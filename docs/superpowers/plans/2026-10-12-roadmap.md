# LILITH — Plan Roadmap

**Spec:** `docs/superpowers/specs/2026-10-12-lilith-design.md` (approved 2026-10-12)

The spec is too large for one implementation plan: M0 + M1a alone is about 700 rules. It is delivered as a series of plans. Each plan produces working, tested software on its own and ends with a review gate. A plan is written in full only when the one before it is done, because spike results and real interfaces change what the next plan says. Rule IDs below show coverage; each plan lists the exact rules it implements.

## M0 results that change later plans

Plan 0 is complete (2026-10-12). The decisions are recorded in the spec as "(M0 result, 2026-10-12: …)" notes and summarised in `docs/spikes/README.md`. Pen input (spike 05) is on hold by project decision and was not run.

- **M1b scope:** the Direct3D 12 path is **not scheduled**. IMG-033 is withdrawn: the in-place composite saved 12.4 % (DXIL) and 6.2 % (DXBC) against the 25 % required. IMG-149's D3D12 bullet is struck through. D3D11 is the only canvas backend.
- **Pins for every plan:** Qt 6.12.0 + Qt WebEngine 6.140.0, cxx-qt 0.10.0, KDDockWidgets 2.4.1 (ARCH-114/115, QA-077). CI installs Qt with `naqt` and `--extensions qtwebengine@6.140.0`, and asserts 6.140.0 (QA-078; plan 1). The git-lfs upgrade source is Git for Windows ≥ 2.56.0.2, with a direct-download fallback because winget lags (OPS-007).
