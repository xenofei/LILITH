## Quirks
- **DeepSeek:** **peak/off-peak pricing active since 2026-08-16** (peak 01:00–04:00 and 06:00–10:00 UTC Mon–Fri excl. Chinese holidays; off-peak = half). Usage `prompt_cache_hit_tokens` + `prompt_cache_miss_tokens` (+ mirrored `prompt_tokens_details.cached_tokens`), `reasoning_tokens`. No `json_schema` (json_object only). With tools, `reasoning_content` must be passed back for **all** earlier assistant turns or 400. Thinking mode rejects forced `tool_choice`. Usage on last content chunk. No rate-limit headers; concurrency limits (2500 flash / 500 pro); keeps connection open with blank lines / `: keep-alive` SSE comments up to 10 min — parser must tolerate. Models: `deepseek-flash`, `deepseek-v4-pro` (old names retired 2026-07-24).
- **Alibaba:** `parallel_tool_calls` defaults **false**; no `tool_choice:"required"`; `json_schema` + `strict` OK; thinking via top-level `enable_thinking`/`thinking_budget`/`reasoning_effort`, `reasoning_content` passback (`preserve_thinking`); `max_completion_tokens` (not `max_tokens`); usage `cached_tokens`, `cache_creation_input_tokens`, `reasoning_tokens`; tiered pricing by input size; explicit vs implicit cache (write 125%/100%, hit ~10%/~20%); night/peak pricing on some models; batch 50%; no rate-limit headers (error codes `Throttling.RateQuota`, `Throttling.AllocationQuota`, `Throttling.BurstRate`, `BudgetLimitExceeded`).
- **Kimi:** temperature 0–1 (k2.6 fixed values); no `tool_choice:"required"` on k2.6/k2.7-code; tool and json_schema `strict` **default true**; thinking `thinking:{type, keep}` (k2.6), always on (k2.7-code, k3 with `reasoning_effort` low/high/max default max); keep `reasoning_content` on earlier turns; cache `prompt_cache_key`, `prompt_cache_options.ttl` 5m/1h; usage `cached_tokens`, `cache_write_tokens`; tiers by cumulative recharge; TPM counts `max_completion_tokens`; moonshot-v1 retired 2026-08-31.
